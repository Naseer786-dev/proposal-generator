# PropGen — Freelancer Proposal Generator

A complete Next.js app for creating AI-powered freelance proposals.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Features

- 5-step wizard for proposal creation
- AI-generated proposal content (mock mode)
- Client-facing proposal view
- Dashboard to track proposals
- No external API keys needed

## No Setup Required

This version works out of the box with:
- Mock AI (no OpenAI key needed)
- In-memory database (no Supabase needed)
- Mock payments (no Stripe needed)
- No authentication required

## Tech Stack

- Next.js 14 + TypeScript
- Tailwind CSS + shadcn/ui
- Mock data layer
